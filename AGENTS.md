# Reglas para agentes

1. Responde siempre en español.
2. Mantén toda la app en un solo archivo (`index.html`) con HTML5, Vanilla JS y Tailwind CSS por CDN.
3. No modifiques ni borres la caché de audios en IndexedDB, la rotación de API keys de Gemini TTS ni el botón Rehacer salvo que el usuario lo pida.
4. Antes de cambios grandes, muestra al usuario qué funciones vas a tocar.
5. Al terminar una edición, haz `git commit` con un mensaje claro en español y ejecuta `git push` a `main`.
